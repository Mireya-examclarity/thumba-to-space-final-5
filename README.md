# Thumba to Space Final 5
My ISRO project for Stardance
A website about India's space journey - from Thumba, Kerala (1963) to Moon, Mars and beyond

### What it does
- **Starfield background** - 150 stars drifting, full spacey vibe
- **Mission Control** - Enter your name and launch rocket from Thumba (real animation, rocket flies up)
- **Gaganyaan countdown** - Days to tentative 2027 window
- **ISS Live tracker** - Shows where ISS is right now
- **NASA APOD** - Astronomy picture of the day
- **Timeline** - Thumba 1963 to Gaganyaan 2027

### Tech
- Flask (python backend)
- HTML / CSS / JS (no framework)
- Deployed using github
